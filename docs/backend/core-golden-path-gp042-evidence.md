Update keeps the existing file, author and kind and validates video edits against the locked row. The write port does not confer general access to Curriculum writes.

The shared encoded JDBC store retains the existing 24-hour receipt TTL. The separate upload operation retains its permanent `file_upload_keys` receipt and the original byte hash and filename/purpose/parent/MIME fingerprint.
- Staged file shared assertions cover owner-visible metadata and download bytes, other-actor absence and rejected discard, same-key replay, and a permanent receipt after discard. Image shared assertions cover attached metadata, identical retry, rejection of changed bytes, and original receipt preservation. Material shared assertions cover authorization facts, stale revision conflict, video-edit rejection on a lesson, and correct revision/order transition.
